# Assets

| Folder | Source | License |
|---|---|---|
| `fonts/` | Manrope static TTFs (Regular, Medium, SemiBold) from https://github.com/googlefonts/manrope | SIL OFL 1.1 (`fonts/OFL.txt`) |
| `icons/` | Lucide SVG icons from https://github.com/lucide-icons/lucide | ISC (`icons/LICENSE`) |
| `glyphs/` | Kenney Input Prompts 1.5 (https://kenney.nl/assets/input-prompts), vector glyphs renamed by Hearth pad position (`<family>/<input>.svg`); only the ones Hearth uses | CC0 (`glyphs/License.txt`) |

Icons use `stroke="currentColor"`; tint them in Slint with the `colorize` property.
