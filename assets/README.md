# Assets

| Folder | Source | License |
|---|---|---|
| `fonts/` | Manrope static TTFs (Regular, Medium, SemiBold) from https://github.com/googlefonts/manrope | SIL OFL 1.1 (`fonts/OFL.txt`) |
| `icons/` | Lucide SVG icons from https://github.com/lucide-icons/lucide | ISC (`icons/LICENSE`) |
| `icons/hearth.svg` | Hearth's own glyph (fireplace with a flame), drawn in Lucide's style; the other files in `icons/` are Lucide | Same license as Hearth (GPL-3.0-or-later) |
| `icons/consoles/` | Original console glyphs drawn for Hearth in Lucide's style (24 px grid, 2 px stroke): hardware silhouettes, never makers' logos. Logical names are system ids (`gc.svg`, `n64.svg`, `psx.svg`…); asset packs can replace them | Same license as Hearth (GPL-3.0-or-later) |
| `controllers/` | `generic.svg`: line-art gamepad generated by `scripts/controller-svg.py` from "Controller & Keyboard Template" by lambdalighthouse (https://lambdalighthouse.itch.io/controller-keyboard-template). The source file goes in `controllers/source/` (not committed: the page allows use and modification but says nothing about redistributing it). `generic.toml`: anchors generated from the drawing by a test | "Free for personal and commercial use, no attribution required" (itch.io page) |
| `sounds/` | Hearth's default UI sounds and ambient loop, synthesized by `scripts/make-default-sounds.py` (needs numpy and ffmpeg to regenerate). Logical names as in `docs/design/README.md` §7; sound packs can replace them | CC0 (`sounds/LICENSE.md`) |
| `glyphs/` | Kenney Input Prompts 1.5 (https://kenney.nl/assets/input-prompts), vector glyphs renamed by Hearth pad position (`<family>/<input>.svg`); only the ones Hearth uses. D-pad directions use the `_outline` variants (pressed side filled), which stay readable when tinted one color | CC0 (`glyphs/License.txt`) |

Icons use `stroke="currentColor"`; tint them in Slint with the `colorize` property.
